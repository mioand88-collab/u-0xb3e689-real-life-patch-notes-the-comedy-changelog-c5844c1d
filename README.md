# Real-Life Patch Notes: The Comedy Changelog

One line of at most 160 characters: a software patch note for a bug in real life — the bladder's impeccable timing, waiting until you are horizontal, lights off, and nearly asleep before raising a P0 ticket.

Running `main.ts` writes that line to `/output/entry.txt`.
